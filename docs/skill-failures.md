# 스킬 실패 기록

스킬이 실제로 틀린 일을 한 줄씩 남긴다. 최신이 위. 같은 원인이 반복되면 다음 개선 대상이다.

원인은 **절차**(단계·규칙이 없거나 틀림) · **도구**(저장된 스크립트가 없거나 낡음) ·
**검증**(잡아낼 확인이 없음) · **입력**(자료가 틀림) · **요구 변경** · **기타** 중 하나.
