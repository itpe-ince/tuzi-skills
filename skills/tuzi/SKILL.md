# tuzi — 라이프사이클 지도

## 한 장 요약

```
  시작          진행             검증         보고          배포         인계
 ┌──────┐   ┌──────┬──────┐   ┌───────┐   ┌────────┐   ┌──────┐   ┌─────────┐
 │start │──▶│  go  │ fix  │──▶│ check │──▶│ report │──▶│ ship │──▶│ handoff │
 └──────┘   └──────┴──────┘   └───────┘   └────────┘   └──────┘   └─────────┘
                 ▲                                                     │
                 └──────────────── 다음 세션은 go 로 받는다 ◀───────────┘

  auto = go → check → report → ship(로컬 커밋) 을 끝까지 한 번에
  team = 여러 에이전트로 나눠 돌릴 때 (분석 → 편성 → 구성 → 위임)
```

## 명령표

| 단계 | 명령 | 이렇게 말해도 된다 | 하는 일 |
| --- | --- | --- | --- |
| 1 시작 | `/start [목표]` | 새 프로젝트 만들어줘 · 이 저장소 파악해줘 | 기준선 측정 · 게이트 확정 · 얇은 끝-끝 경로 · `CLAUDE.md`/`HANDOFF.md` 뼈대 |
| 2 진행 | `/go [할 일]` | 진행해 · 계속해 · 알아서 해 | 중단 지점 복원 → 한 수 착수 → 끝까지 |
| 2 고치기 | `/fix [증상]` | 근본 원인 해결해줘 · 또 같은 문제야 | 원인 한 문장 → 재현 → 같은 구멍 → 강제자 |
| 3 검증 | `/check [대상]` | 확인해봐 · 띄워줘 · 캡처 남겨줘 | 실물 기동 → 증거 파일 → 확인/미확인 분리. 1라운드 |
| 4 보고 | `/report [형식]` | 보고해줘 · 대조표 · 워드로 만들어줘 | 파일·기존·변경후 3열 + 이유 + 영향 파일. 문서 산출물 |
| 5 배포 | `/ship [push\|pr\|deploy]` | 커밋해줘 · pr 올려줘 | 게이트 → 브랜치 → 경로 add → 로컬 커밋. 바깥은 확인 |
| 6 인계 | `/handoff` | 세션 넘겨 · 인수인계 문서 | 다음 세션이 `go` 한 번으로 받을 수 있게 남긴다 |
| 끝까지 | `/auto <목표>` | 끝나면 알려줘 · qa 끝나면 갭까지 | 2→3→4→5(로컬) 를 멈추지 않고 |
| 팀 | `/team [plan\|setup\|run\|status]` | 프로젝트 분석해서 에이전트 구성해줘 · 워커에 맡겨 | 분석 → 워커 명단 설계 → 구성 → 위임 · 조회한 상태만 보고 |

**하나만 기억한다면** — 작업을 시작할 때 `/go`, 끝까지 맡길 때 `/auto`.

## 이 명령이 호출되면

1. 위 지도를 그대로 보여준다
2. `git status --short` · `git log --oneline -3` · `HANDOFF.md` 유무를 보고
   **지금 부를 명령 하나**를 이유 한 줄과 함께 권한다

| 저장소 상태 | 권할 명령 |
| --- | --- |
| 저장소가 비었거나 게이트·실행 방법을 모른다 | `start` |
| `HANDOFF.md` 가 있거나 작업 중인 브랜치다 | `go` |
| 미커밋 변경이 있고 확인 기록이 없다 | `check` |
| 확인을 마친 미커밋 변경이 있다 | `ship` |
| 실패·버그 이야기 중이다 | `fix` |

## 단계 사이의 공통 규칙

모든 단계가 같이 지킨다. 각 스킬 안에 다시 적혀 있다.

- **되묻지 않는다** — 워크트리 안의 일은 하고 나서 보고한다. 바깥(push·운영 DB·외부 전송)만 묻는다
- **돌려 보지 않은 것을 됐다고 적지 않는다** — 확인한 것과 안 한 것을 나눠 적는다
- **없는 식별자를 만들지 않는다** — 근거로 인용할 번호는 저장소에 실제로 있는 것만
- **도구를 지명하지 않는다** — 그 환경에 있는 것을 찾아 쓰고, 없으면 없다고 적는다
