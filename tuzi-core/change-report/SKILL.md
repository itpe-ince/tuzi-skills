# 변경을 보고한다

## 왜 이 스킬이 있나

`보고` 가 사람이 쓴 메시지의 **9.7%(132건)** 로 2위다. `대조표 만들어줘` 같은 직접
요구도 나온다. 보고가 일을 덜어 주지 못하면 사용자는 결국 디프를 직접 연다 —
그때 보고는 비용이지 산출물이 아니다.

## 네 규칙

각 규칙 앞에 **무엇이 실제로 잘못되는지**를 적는다. 규칙만 있으면 지켜지지 않는다.

### 1. 없는 식별자를 만들지 않는다

> 무슨 일이 일어나나 — 모델은 그럴듯한 구조를 좋아해서, 사용자가 준 적 없는
> "Task 1", "Req A", "Phase 2" 를 지어내 근거처럼 인용한다. 읽는 사람은 그런 번호가
> 어딘가에 있다고 믿고 찾으러 간다. 없다.

근거로 인용할 번호는 저장소의 **실제** 문서·이슈·티켓에 있는 것만 쓴다. 없으면
번호 없이 서술한다. 인용하기 전에 `grep` 으로 그 ID 가 저장소에 있는지 본다.

### 2. [파일명] · [기존 동작] · [변경 후 동작] 을 대조한다

> 무슨 일이 일어나나 — "개선했습니다", "수정했습니다" 로 끝난다. 읽는 사람은 무엇이
> 어떻게 달라졌는지 알 수 없어 결국 디프를 직접 열어 본다.

세 값을 나란히 놓는다. **"기존 동작"은 코드 모양이 아니라 동작이다** —
"함수가 20줄이었다"가 아니라 "만료를 검사하지 않았다".

| 파일 | 기존 동작 | 변경 후 동작 |
| --- | --- | --- |
| `auth/session.ts` | 만료를 검사하지 않아 지난 토큰도 통과했다 | `exp` 를 현재 시각과 대조해 지난 토큰을 거부한다 |

### 3. 이유와 영향 파일을 함께 밝힌다

> 무슨 일이 일어나나 — 무엇을 고쳤는지는 말하고 **왜**와 **어디에 번지는지**는
> 빼먹는다. 그래서 호출부가 깨지거나, 고쳐야 할 테스트가 남거나, 같은 문제가 돌아온다.

수정 이유를 적고, 이 변경으로 의존이 생겼거나 영향받는 파일을 명시한다.
호출부·임포트·설정·테스트까지. **영향이 없으면 "없음"이라고 적는다** — 빈칸으로
두지 않는다. 빈칸은 "안 봤다"와 구별되지 않는다.

### 4. 적기 전에 파일과 대조한다

> 무슨 일이 일어나나 — "고쳤다"고 적었는데 파일에 없었다. 치환 스크립트가 중간에
> 죽어 앞선 치환까지 날아갔는데 성공 로그(`✓`)는 이미 출력돼 있었다. 다음 단계
> 검토자가 "인용한 ID 가 저장소에 없다"로 찾아냈다.

- `git show --stat HEAD` 로 **의도한 파일만 들었는지** 본다
- 새 ID·새 행을 넣었으면 `grep` 으로 결과를 확인한다
- 성공 로그와 파일 상태가 어긋나면, 사람은 로그를 믿고 검증을 건너뛴다

## 보고의 뼈대

```
## 무엇을 했나
(한 문단. 결과부터)

| 파일 | 기존 동작 | 변경 후 동작 |
| --- | --- | --- |

**이유** — …
**영향 파일** — 호출부 `x.ts`, 테스트 `x.test.ts`, 설정 `.env.example`. (또는 "없음")

## 확인한 것 / 확인하지 않은 것
(`verify-for-real` 스킬 참조)
```

## 텍스트 디프를 붙이지 않는다

`git diff` 출력을 통째로 붙이면 좌우 대조가 안 되고, 이 수정이 어디까지 번지는지는
아예 보이지 않는다. 정보는 많은데 읽히지 않는다. 대신:

- **ASCII 트리** — 어느 폴더의 무엇이 얼마나 바뀌었는지 가벼운 요약. 답변에 인라인
- **표** — 3열 대조. 기본값
- **흐름도** — 변경 파일에서 뻗어나가는 영향 범위가 핵심일 때만
- 추론으로 그린 선·점선은 **추론이라고 말한다.** 단정하지 않는다

도구 이름을 지명하지 않는다. 쓸 수 있는 시각화 도구가 있으면 쓰고, 없으면 표와
트리로 쓴다. 도구가 사라지면 거짓이 되는 규칙은 두지 않는다.

## 사소한 작업

오타·1줄 수정처럼 사소한 것은 위 규약만 지켜 **한 줄로** 보고한다. 표를 만들지 않는다.

## 문체

사용자에게 말하는 본문은 **존댓말**이다. 커밋 메시지·설계 문서·코드 주석은 저장소
문체를 따른다 — 이 규칙은 **사용자에게 하는 보고**에만 적용된다. 저장소 문서의
압축된 아포리즘 문체를 대화형 보고로 옮기지 않는다.
